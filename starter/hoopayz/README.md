# HooPayz starter application

Follow the [project guide](../../README.md) for the trip scenario, milestones,
helper contracts, checks, and submission instructions. This folder contains the
learner scaffolding. Run all npm commands here (`starter/hoopayz` from the
repository root).

Use Node.js 24 LTS. Start with `npm run test:setup`, then `npm start` and open
http://localhost:4175. To use another port, run `npm start -- 4176` and open
http://localhost:4176. Learner-task failures are expected until you complete the tasks.
